Architecture Overview

One Flask application. Every agent action passes through the same middleware, then one handler.

Browser Hub, resume, jobs, research, review, and observability pages
Flask routes Sign-in and session role, then the page or API for that action

Middleware, same order every time

1Bind the user
2Trim the text
3Input guardrail
4Open a trace
5Run the handler
6Output guardrail
Resume

Parse PDF or DOCX, score ATS, match roles, list skill gaps, roadmap, and practice.

Jobs

LinkedIn and Naukri by city and posting date. Live Apify, or the local catalog.

Research

Gemini answers from the uploaded paper, or returns an IEEE draft from a repository link.

Review

Candidate, hiring manager, or auditor approves, rejects, or corrects the result.

Oversight Safety alert log, trace log, and the local evaluation suite on the Observability page
